# DBML Studio

DBML ファイルをタブで開き、ER 図とテキストのどちらからも編集できる Windows デスクトップアプリです。オフラインで動作します。

## インストール

[最新リリース](https://github.com/RoboticsY/dbml-studio/releases/latest)から Windows x64 用のセットアップファイルをダウンロードして実行してください。インストール後はスタートメニューから「DBML Studio」を起動できます。

## 編集と自動保存

- 「開く」で複数の DBML ファイルを選べます。図のテーブル、カラム、参照線を選ぶと、右側に編集項目が表示されます。「DBML テキスト」でテキストエディタも開けます。
- 編集が約 1.2 秒止まると、変更したタブの内容を検査して整形し、自動保存します。別のタブへ移っても保存されます。新規文書の下書きは、自動保存後に画面下に表示されるフォルダー（通常は `%LOCALAPPDATA%\DBML Studio\Drafts`）にあります。「保存」で名前と保存先を指定できます。
- テキスト入力中も DBML を検査します。エラーがある間は直前の図を表示し、ディスク上の DBML を保持します。修正すると自動保存が再開します。ファイルが外部で変更された場合は、内容を確認してから別名で保存してください。
- テーブルの見出しをドラッグすると配置が変わります。座標は同じフォルダーの `ファイル名.dbml.layout.json` に自動保存します。別のフォルダーや PC に図を移すときは、DBML と配置ファイルを一緒にコピーしてください。
- 図の PK は主キー、FK は外部キーを示します。列挙型や複合参照などの定義はテキストで編集できます。使用しているパーサーは `TablePartial` や `Records` など一部の構文に対応していません。

## ソースからビルド

Windows x64、Rust の MSVC ツールチェーン、Visual Studio の C++ ビルドツールを使用します。

```powershell
cargo test --locked
cargo run --release --locked
```

インストーラーの作成には NSIS 3 と PowerShell を使います。`makensis` を PATH に追加したうえで、リポジトリのルートから実行してください。

```powershell
./installer/build.ps1
```

セットアップファイルは `dist` に出力されます。
